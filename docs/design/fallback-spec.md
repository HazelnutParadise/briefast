# Briefast 設計 spec（三版共同輸入）

## 產品是什麼

Briefast——每日產業與股市新聞報告網站。每個交易日開盤前，AI agent 從公開新聞判讀出個股多空觀點並整理產業摘要，推送到網站；讀者開站即看到當天報告，也能回看歷史。它不是行情看盤軟體、不是新聞聚合器，而是「一份每天早上出刊、有觀點的晨報」。網站是唯一產品介面，公開瀏覽、無帳號系統。

## 目標受眾與使用場景

台灣的散戶投資人與關注股市的上班族。典型場景：早上 07:50–09:00 之間，通勤或喝咖啡時用手機或桌機打開，花三到五分鐘掃完當天報告就去開盤。第二場景：收盤後或週末回頭翻歷史報告，驗證當初的判斷。閱讀模式是「快速掃讀＋選擇性細讀」——先掃多空結論，有興趣才往下讀個股詳情。

## 核心內容與區塊（真實內容取自 v5 wireframe，三版共用、不得換成 Lorem）

首頁由上而下固定六個部分：

1. **Masthead**：品牌名 Briefast、副標「每日產業與股市報告」、報告日期（2026 年 8 月 7 日（四）開盤前 07:50 更新）、「歷史報告」入口。
2. **盤前總覽**：兩段文字（美股四大指數收紅、費半大漲、今日焦點台積電營收與美國 CPI）。
3. **今日觀察**：三條條列（台積電 7 月營收、美國 CPI、外資期貨空單）。
4. **個股多空判斷**（全站核心）：四組——短期看漲（台積電 2330、緯創 3231）、短期看跌（長榮 2603）、長期看好（台達電 2308）、長期看壞（某面板股）。每檔附一句理由。
5. **產業新聞摘要**：四個產業卡（半導體、AI／雲端、金融、傳產／能源），各一至兩條要聞。
6. **個股新聞詳情**：六條，每條含股名代號、多空標籤（鴻海 2317 為中性無標籤）、摘要段落、來源新聞名。
7. **免責聲明頁尾**：AI 彙整、僅供參考、不構成投資建議。

歷史頁：日期新到舊列表（每列日期＋一句 headline）＋分頁。demo 至少要示意歷史頁入口與一小段列表（可做成同頁的第二區或連結示意）。

## 情感基調與氣質關鍵詞

專業、冷靜、快、可信；有觀點但不炒作、不喊單。像一份嚴肅財經刊物的頭版，不像券商 App 的促銷頁。資訊密度可以高，但必須可掃讀——標籤、層級、節奏要讓人三秒抓到「今天誰多誰空」。氣質關鍵詞：晨報、判斷、對立（多 vs 空）、日更節律。

## 視覺母題假設

這個內容獨有的結構是「**多空對立**」（紅 vs 綠的二元張力）與「**日刊性**」（日期是報告的身分）。好的設計應讓這兩件事成為版面主角，而不是通用卡片牆。

## 輸出格式與尺寸（三版統一，硬性）

- 單檔 HTML（內嵌 CSS，可用 Google Fonts CDN），存 `docs/design/design-demos/<版名>.html`。
- 桌機版面以 **1440px 寬**為設計基準；須宣告 `<768px` 的收合方式（實際媒體查詢至少讓 375px 不破版）。
- 截圖：`npx playwright screenshot file:///<路徑> <版名>.png --viewport-size=1440,900 --full-page`，存同目錄。截圖工具失敗不擋交付，回報即可。

## 已知約束（硬性，任何風格不得違反）

- **台股慣例紅漲綠跌**：看漲／看好一律紅系、看跌／看壞一律綠系，不得反轉、不得改用歐美綠漲紅跌。色值可依整體配色調校，但語意方向不可變。
- 繁體中文為主要語言，台灣用語；中文引號用「」。
- 免責聲明頁尾必須存在且可讀。
- 正文 ≥14px、標籤 ≥12px、正文對比 ≥4.5:1。
- 不用照片、不用 SVG 手繪插畫、不用 emoji 當 icon；純排版與資料語言完成設計。
- 不出現購買／註冊 CTA——這是內容刊物，不是行銷頁。
- 最終產品會做深淺雙主題；demo 以你風格的原生主題呈現單一主題即可，但在 HTML 註解中附另一主題的色彩 token 建議。

## 內容誠實

所有數字與新聞為示意假資料（wireframe 既有內容），不得再捏造精確到小數的新統計數字加戲；股名沿用現有清單。
