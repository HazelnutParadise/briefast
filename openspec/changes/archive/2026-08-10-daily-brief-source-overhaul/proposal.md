## Summary

daily-brief skill 的設定來源、新聞來源端點與判讀流程全面校準到實測可用的狀態：設定改讀工作區 .env、來源表換成逐一驗證過的端點、判讀拆成產業與個股兩輪並各自附重要程度排序依據。

## Motivation

三個實際問題：

1. **設定介面不可用**：skill 現在要求讀環境變數，但 Cowork 執行環境沒有注入環境變數的介面，agent 拿不到 BRIEFAST_URL 與 BRIEFAST_API_KEY。skill 是可攜的操作手冊，秘密應留在各執行工作區。
2. **來源表與現實脫節**（2026-08-09 逐一實測）：UDN 所有公開 RSS 都是空殼（item 存在但 title 與 link 全空）；CTEE 其實有純 HTTP 可取的 RSS 端點，現行「無頭瀏覽器」的取得方式是不必要的重裝備；cnyes 列表 API 本身就含全文與股票標注，不需要抓詳情頁；TWSE 爬太快會被鎖 IP，但 skill 沒有節流規則。
3. **判讀缺乏重要程度概念**：產業與個股混在同一輪判讀，沒有排序依據，執行模型無從決定哪些事件該領銜、該深寫，摘要詳略全憑臨場發揮。

## Proposed Solution

1. **設定讀工作區 .env**：skill 改為從執行工作區根目錄的 .env 檔讀 BRIEFAST_URL 與 BRIEFAST_API_KEY（KEY=VALUE 格式）；檔案不存在或缺鍵即觸發既有中止點，不蒐集不組稿不 POST。skill 目錄新增 .env.example 範本（只有鍵名與說明，無真值）；repo 的 .gitignore 加入 .env。不顯示、不記錄 key 的規則不變。
2. **來源表改版為已驗證端點**：
   - 鉅亨網：分類列表 API 六類——tw_stock（個股）、headline（頭條）、tech（科技）、tw_macro（總經金融）、cnyeshouse（房產）、wd_stock（國際，只餵 overview_md）；列表回應即含全文與股票標注，不另抓詳情頁。
   - 證交所：t187ap04_L（重大訊息）、t187ap05_L（月營收）兩資料集整包拉回後依時間窗口過濾；新增節流規則——序列請求、間隔至少 5 秒，遇 429 或連線被拒等 60 秒重試一次，仍失敗依既有規則當次要來源失敗處理。
   - 工商時報：改用 rss_web/livenews 六分類 RSS（policy、stock、finance、industry、house、tech），文章內文以一般 HTTP 直接抓取；移除無頭瀏覽器需求。
   - 中央社：財經 RSS（feedburner rsscna/finance）。
   - 科技新報：全站 feed。
   - 聯合新聞網：移除（feed 全空殼），由自由時報財經 RSS（news.ltn.com.tw/rss/business.xml）補位。
3. **兩段式判讀與排序依據**：判讀拆為先產業輪、後個股輪。每輪動筆前先依該視角的排序依據把窗口內新聞排重要程度：產業輪依（一）價格與供需已實際變動（二）政策監理將強制生效（三）波及廣度（四）持續性（五）確定性；個股輪依（一）獲利衝擊已可量化（二）事實層級（三）反映時點（四）競爭地位改變（五）籌碼資金面僅作佐證。排序只影響摘要的詳略、著墨深度與事件先後，不得用來篩選收錄與否；「不設數量上限、能判斷的都列」規則不變。排序的持續性判準同時反映在寫法上：著墨深的事件在內文標明屬週期內波動或結構性改變。
4. **撰寫訣竅（經辯論修訂）**：兩輪各附分析師撰寫訣竅，全部綁定「來源限新聞載明或本次抓取」與「缺料就省略、不寫佔位句」兩道護欄。產業輪四條——數字含方向、幅度、期間與基準且以新聞載明為限；供需歸因附持續性含義，驅動不明就明寫不明（唯一允許明寫缺料的條目）；影響分佈寫誰受益、誰承壓、誰能轉嫁；深寫事件標明週期或結構。個股輪五條——首句寫這則新聞改變了什麼判斷且比 headline 深一層，call none 首句寫為何無法判斷；量級換算算得出（本次抓到基準數字）才寫、算不出直接省略；預期差限新聞載明的預期或已登記事件；公關語言還原為事實，沒數字的合作降級為意向；具名歸因以新聞載明為限，模糊主詞保留模糊並降事實層級。附反例→正例對照表並註明為示意，不是可複製的範本句。

## Non-Goals

- 不動 Go 程式、報告 schema、網站版面與 API 行為。
- 不把 .env 讀取做成程式碼或共用腳本；它是 SKILL.md 的操作指示。
- 不新增排序分數欄位到報告 JSON；排序是判讀過程的內部依據，不進輸出。
- 不擴充新聞來源到上表以外，也不恢復 UDN；若日後 UDN feed 復活另案處理。
- 不改變來源成敗把關的主次分流（鉅亨網仍是唯一主來源）。
